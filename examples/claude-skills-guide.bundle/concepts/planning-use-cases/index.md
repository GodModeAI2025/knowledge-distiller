# Planning & Use Cases

How to identify and define what a skill should do

* [Skill Use Case Categories](skill-use-case-categories.md) — Anthropic has identified three canonical skill use case categories based on patterns observed across early adopters and internal teams: (1) Document and Asset Creation, (2) Workflow Automation, and (3) MCP Enhancement.
* [Use Case Definition & Success Criteria](use-case-definition.md) — Before writing any skill instructions, identify 2-3 concrete use cases. A good use case definition specifies: trigger phrase, ordered steps, tools required, and expected result. Success criteria are defined both quantitatively (trigger rate, tool call count, API error rate) and qualitatively (user autonomy, output consistency).
