# Knowledge Distiller v4.0

> Extract **Knowledge**, Not Text.

An AI agent skill that distills any document into structured knowledge graphs with temporal
awareness. Atomic concepts, explicit relationships, time context, zero redundancy — backed by a
**formal, machine-checkable format** and **deterministic tooling**.

**Dual Output:** `.knowledge.md` (human-readable, Obsidian-compatible) + `.knowledge.json`
(machine-readable, JSON-LD graph) — plus an optional self-contained HTML viewer and a scalable
directory bundle.

## What It Does

| What it does NOT do | What it DOES |
|---|---|
| 1:1 transcript of the document | Identify and describe concepts atomically |
| Copy-paste with Markdown formatting | Make relationships between concepts explicit |
| Rebuild the table of contents | Eliminate redundancy (same idea = one block) |
| Let an LLM grade its own output | Enforce the format in code (validator + tests) |

## Key Features

- **Knowledge Graph** — Rich nodes with definitions, statements, relevance. Weighted, typed edges. JSON-LD with schema.org context.
- **Formal Spec** *(v4.0)* — The output is defined in [`SPEC.md`](SPEC.md) and mirrored by a JSON Schema ([`schema/knowledge.schema.json`](schema/knowledge.schema.json). The spec is the single source of truth.
- **Deterministic Validation** *(v4.0)* — [`scripts/validate_knowledge.py`](scripts/validate_knowledge.py) enforces the contract and computes a reproducible `quality_score`. No LLM self-grading.
- **Computed, Not Authored** *(v4.0)* — Counts, the Concept Map, the Mermaid block, cluster membership and `index.md` files are generated by code (`scripts/build_graph.py`, `build_md.py`) so they never drift.
- **Auditable Citations** *(v4.0)* — Statements carry `[n]` markers resolving to a numbered `## Quellen` list; every fact is sourced. A `resource` field gives concepts a canonical identity for cross-source dedup.
- **Monotonic Merge** *(v4.0)* — Incremental merges only ever enrich the graph; a shrinking merge fails validation. Conflicting values become a **time series**, not a destructive overwrite.
- **Temporal Dimension** *(v3.1)* — Three temporal layers: source period, validity range, distillation date. Every node, fact and chunk carries time context.
- **Scalable Bundle** *(v4.0)* — Optional one-file-per-concept directory layout with `index.md` manifests for large corpora (clean git diffs, progressive disclosure).
- **Self-Contained Viewer** *(v4.0)* — `scripts/build_viewer.py` renders an offline, interactive `.knowledge.html` (Cytoscape graph, color-by-cluster, "Cited by" backlinks, greyed-out superseded nodes).
- **Embedding-Ready Chunks** — Clean-text chunks (`chunks[].text`) without Markdown syntax. Each starts with a natural-language time reference.
- **Obsidian Wikilinks** — `[[concept]]` syntax for cross-references. Drop into your vault.
- **Any File Format** — PDF, DOCX, PPTX, XLSX, CSV, JSON, HTML, TXT, images, URLs.

## Format Spec & Tooling

The format is no longer just prose — it is a contract:

- **[`SPEC.md`](SPEC.md)** — the authoritative definition (RFC-2119, conformance section, versioning). When SKILL.md and SPEC.md disagree, **SPEC.md wins.**
- **[`schema/knowledge.schema.json`](schema/knowledge.schema.json)** — the machine-checkable mirror (JSON Schema 2020-12).

| Script | Purpose |
|---|---|
| `scripts/validate_knowledge.py <json>` | Validate against SPEC/schema; split errors/warnings; reproducible `quality_score`. `--prev <old>` enforces the merge monotonicity contract. |
| `scripts/build_graph.py <json> --write` | Recompute counts, cluster membership, canonical edge ids, `quality_score`. |
| `scripts/build_md.py <json>` | Render `.knowledge.md` deterministically from the graph. |
| `scripts/build_bundle.py <json> -o <dir>` | Explode the graph into a directory bundle (SPEC §7). |
| `scripts/build_viewer.py <json>` | Generate the self-contained `.knowledge.html` viewer. |

```bash
# validate the shipped example, then rebuild its views
python3 scripts/validate_knowledge.py examples/claude-skills-guide.knowledge.json
python3 scripts/build_md.py examples/claude-skills-guide.knowledge.json
python3 scripts/build_viewer.py examples/claude-skills-guide.knowledge.json
python3 -m pytest tests/      # 21 golden tests
```

Pure standard library; the optional `jsonschema` package adds schema-level validation on top of
the structural checks.

## Temporal Dimension (v3.1)

When you distill documents across years, knowledge without a time axis creates contradictions.
"Revenue: 28B" and "Revenue: 34B" aren't conflicting facts — they're a time series. As of v4.0
the **monotonic merge** actually realizes this: conflicting values are kept as distinct temporal
entries with a `tension`/`replaces` edge, instead of one value overwriting the other.

| Layer | Fields | Purpose |
|---|---|---|
| **Source** | `source_date`, `source_period` | When was the knowledge published? |
| **Validity** | `valid_from`, `valid_until` | When does this information apply? |
| **Distillation** | `distillation_date` | When was the extraction performed? |

**Time formats:** ISO 8601 with flexible granularity — `2024-12-31`, `2024-Q4`, `FY2024`, `2020/2024`

**Temporal confidence:** `explicit` (date stated in document) / `inferred` (derived from context) / `unknown`

## Graph Schema

Eight relationship types (closed vocabulary, enforced by the validator):

| Type | Meaning | Symbol |
|---|---|---|
| `uses` | Dependency | → |
| `enables` | Causality | → |
| `based-on` | Foundation | → |
| `part-of` | Composition | → |
| `tension` | Trade-off / Contradiction | ↔ |
| `replaces` | Supersession | → |
| `extends` | Extension | → |
| `example-of` | Instantiation | → |

## Works With

| Tool | How |
|---|---|
| **Web browser** | Open `.knowledge.html` — a zero-install interactive graph (offline). |
| **Obsidian** | Drop `.knowledge.md` files (or a bundle) into your vault. Wikilinks create a navigable graph. |
| **Neo4j / Gephi** | Import `.knowledge.json` nodes and edges directly. |
| **OpenAI / Cohere Embeddings** | Use the `chunks[].text` field — clean text, no syntax artifacts. |
| **RAG Pipelines** | Each chunk is self-contained with time context. Ready for LangChain / LlamaIndex. |
